Benefícios da infraestrutura como código

Repetibilidade

O mesmo código cria o mesmo ambiente, quantas vezes for preciso.

Revisão antes da mudança

O terraform plan mostra o impacto antes de qualquer alteração.

Histórico no Git

Cada mudança de infraestrutura fica registrada e pode ser revisada.

Serviços AWS deste laboratório

S3

Amazon S3

Armazena os arquivos do site em um bucket privado.

CF

Amazon CloudFront

Distribui o conteúdo por HTTPS com cache global.

OAC

Origin Access Control

Permite que apenas o CloudFront leia o bucket.

Sobre o Terraform

O Terraform descreve recursos em arquivos .tf, monta um grafo de dependências e aplica as mudanças na ordem correta. Aqui, o bucket é criado primeiro, depois o CloudFront e, por fim, a política que liga os dois.
